Learn Morse code offline. 离线学习摩尔斯电码。

MorseCQ is an account-free, offline Morse code trainer. Learn the code with structured Koch lessons, receive drills and sending practice. Morse chat lives in DitMesh. MorseCQ 是无需账号、无需联网的摩尔斯电码训练器。通过 Koch 课程、抄收练习和拍发练习学习电码。摩尔斯聊天请使用 DitMesh。

Learn学习

A real course, not a flashcard deck一套真正的课程，而不只是闪卡

MorseCQ teaches the way experienced operators recommend: characters at full speed from day one, new ones added only when you copy the current set reliably.MorseCQ 按资深报务员推荐的方式教学：从第一天起就以全速发音学字符，只有当前字符抄收稳定后才加入新字符。

  • Koch method — 42 lessons with progress stored per identity.Koch 教学法——42 课，进度按身份分别保存。
  • Farnsworth spacing — fast characters, generous gaps while you learn.Farnsworth 间距——字符快速，字间留足思考时间。
  • Spaced repetition — characters you miss come back when they are due.间隔重复——抄错的字符会在到期时再次出现。
  • Daily goals and streaks to keep a little practice going every day.每日目标与连续打卡，每天都练一点。

Send practice works on an on-screen straight key or iambic paddle, and on the desktop keyboard. How a practice round works一次练习是怎么进行的

  1. 1

    You key it你拍发

    Type, tap a straight key or squeeze a paddle. MorseCQ decodes your keying into text.打字、点手键或按双桨电键，MorseCQ 把你的拍发解码成文字。

  2. 2

    MorseCQ evaluates itMorseCQ 评估

    The trainer checks timing, accuracy and rhythm locally, then records the result in your on-device progress.训练器在本机检查节奏、准确率与拍发质量，再把结果写入本地进度。

  3. 3

    You hear it你听到反馈

    Replay the prompt and your own keying at the speed and tone you choose, then try again.按你选择的速度和音调回放题目与自己的拍发，然后继续练习。

FAQ

Do I need an amateur radio licence?需要业余无线电执照吗？

No. MorseCQ works offline, not over the airwaves — anyone can learn without an account or internet connection. If you are a licensed operator, it is a great way to keep your CW sharp between contacts.不需要。MorseCQ 无需联网，任何人都可以学习。如果你持有执照，它也是在两次上机之间保持 CW 手感的好办法。

Does practice need an internet connection?练习需要联网吗？

No. MorseCQ is an account-free, offline trainer. Lessons, drills, materials and progress run on your device. Chat is a separate product: use DitMesh.不需要。MorseCQ 是无需账号、无需联网的训练器，课程、练习、素材与进度都在本机运行。聊天功能属于独立产品，请使用 DitMesh。

Where is Morse chat?摩尔斯聊天在哪里？

MorseCQ 1.0.1 is the offline trainer. Morse chat moved to DitMesh, the separate app for conversations.MorseCQ 1.0.1 是离线训练器。摩尔斯聊天已移到独立应用 DitMesh。

Do I need an account to practise?练习需要账号吗？

No. Start learning immediately; your training progress and settings are stored locally on the device.不需要。打开应用即可开始学习，训练进度与设置保存在本机。

Why does my system warn me when I install it?为什么安装时系统会弹出警告？

Pre-alpha builds are not yet code-signed or notarized. On macOS right-click the .pkg and choose Open (or run xattr -d com.apple.quarantine <file>); on Windows choose More info → Run anyway in SmartScreen. The Android APK uses a debug key, so a future store build will not upgrade it in place. Verify downloads against SHA256SUMS.Pre-alpha 版本尚未代码签名或公证。macOS 上请右键 .pkg 选择「打开」（或执行 xattr -d com.apple.quarantine <文件>）；Windows 上在 SmartScreen 中选择「更多信息 → 仍要运行」。Android APK 使用 debug 签名，将来的商店版本无法直接覆盖升级。可用 SHA256SUMS 校验下载文件。

Does MorseCQ include chat or calls?MorseCQ 包含聊天或通话吗？

No. MorseCQ is focused on offline learning. Use DitMesh for Morse chat.不包含。MorseCQ 专注离线学习；摩尔斯聊天请使用 DitMesh。

Is it really free?真的免费吗？

Yes. MorseCQ is free software under the GNU General Public License v3.0. Bug reports and contributions are welcome on GitHub.是的。MorseCQ 是遵循 GNU GPL v3.0 的自由软件，欢迎到 GitHub 提交问题和贡献代码。
